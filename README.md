# Global Layoffs Analysis — SQL Data Cleaning & Exploratory Analysis

## Objective

The goal of this project is to clean and analyze a global layoffs dataset using SQL to identify major layoff trends across companies, industries, countries, company stages, and time periods. The project focuses on preparing raw data for analysis and using SQL queries to uncover patterns in layoffs and identify companies with the highest number of employees laid off.
