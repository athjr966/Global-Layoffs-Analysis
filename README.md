# Global Layoffs Analysis - SQL Data Cleaning & Exploratory Analysis

## Objective

The goal of this project is to clean and analyze a global layoffs dataset using SQL to identify major layoff trends across companies, industries, countries, company stages, and time periods. The project focuses on preparing raw data for analysis and using SQL queries to uncover patterns in layoffs and identify companies with the highest number of employees laid off.

## Key Questions

## Data Cleaning
1. Remove duplicates 
2. Standardize data
3. Removing null values or blank values 
4. Remove any columns or rows

## Data Exploratory 

1. **Overall Layoff Scale**
What are the maximum numbers and percentages of employees laid off in the dataset?

2. **Companies with 100% Layoffs**
Which companies laid off 100% of their employees?

3. **Companies with the Most Layoffs**
Which companies recorded the highest total number of employees laid off?

4. **Layoff Date Range**
What is the earliest and latest layoff date recorded in the dataset?

5. **Layoffs by Industry**
Which industries experienced the highest number of layoffs?

6. **Layoffs by Country**
Which countries recorded the highest number of layoffs?

7. **Layoffs by Year**
How did the total number of layoffs change from year to year?

8. **Layoffs by Company Stage**
Which company stages experienced the highest number of layoffs?

9. **Layoff Percentage by Company**
Which companies had the highest cumulative layoff percentages?

10. **Monthly Layoff Trends**
How did the number of layoffs change month by month?

11. **Cumulative Layoffs**
How many layoffs accumulated over time?

12. **Yearly Company Layoffs**
Which companies recorded the highest number of layoffs in each year?

13. **Top 5 Companies by Year**
Which five companies had the highest number of layoffs in each year?
